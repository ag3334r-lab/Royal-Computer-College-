## ✨ Features

- **Home & Course Marketplace:** Search and filter courses across AI & Data Science, Web Development, Graphic Designing, Cyber Security, and Digital Marketing.
- **Course Curriculum & Live Classroom:** Interactive video classroom (`/class/:id`) with live student chat and module breakdown.
- **Knowledge Check Quizzes:** Interactive multiple-choice assessments (`/quiz/:id`) with instant scoring.
- **Role-Based Dashboards:** Dedicated Student, Teacher, and Admin dashboards with progress tracking and analytics.
- **Royal AI Assistant:** Integrated Gemini AI learning assistant.
